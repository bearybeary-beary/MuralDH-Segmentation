# MuralDH Segmentation Subset

> A reorganized subset of the MuralDH dataset for mural damage segmentation research.

## 📋 Overview

This repository provides a reorganized version of the **damage segmentation subset** from the [MuralDH dataset](https://github.com/tearsheaven/MuralDH) [1]. The original dataset contains 1,000 images with pixel-level damage annotations (cracks, flaking, fading) [6†L6-L13].

This version retains only the segmentation subset and re-splits it into **training**, **validation**, and **test** sets for easier model development and benchmarking.
